# 💳 FinTech Digital Wallet & Payments System

A secure, full-stack **digital wallet and payment management system** built with React.js, Node.js, PostgreSQL, and Payment Gateway APIs.

The application allows users to manage their wallet, send and receive money, make payments, view transaction history, analyze spending patterns, and protect their accounts with two-factor authentication.

---

## 📌 Project Overview

The **FinTech Digital Wallet & Payments System** is designed as a modern financial application that provides users with a secure way to manage digital money and perform peer-to-peer transactions.

### Core capabilities

- User registration and authentication
- Secure wallet management
- Wallet balance tracking
- Peer-to-peer payments
- Payment gateway integration
- Transaction history
- Transaction details
- Two-factor authentication
- Security activity monitoring
- Payment analytics
- User profile management
- Notification preferences
- Account management
- Protected routes
- Responsive dashboard
